# 2026年11月 条件表の承認LOCK

ユーザーが確認した最終Wordの現物を承認対象とする。承認範囲は条件文書・金額であり、メールの宛先・本文・添付方式・送信の承認は含まない。

2026年11月はNew Island株式会社を配信対象から除き、keioh・ネットコネクト・その他8社の計10社、通常条件とキャンペーン各1件の合計20件をLOCKした。keiohはユーザーが成果物フォルダへ追加した2件、ネットコネクトとその他8社はユーザーの手動修正を含む現在のファイルを採用し、金額を再計算・再生成していない。New Islandの生成済み2件と含有ZIPを削除し、その他8社の16件ZIP・一覧へ更新した。10月原本・過去の分析資料は履歴として保持する。

## 保存先

- `04_成果物/2026-11_LOCK/documents/`：承認済み20件のバイト単位で同一のスナップショット。
- `04_成果物/2026-11_LOCK/manifest.json`：10社の有効対象、New Islandの除外、各正本・コピーのパスとSHA256。
- `04_成果物/2026-11_LOCK/amounts.json`：表・行・セル単位の金額欄。テキストボックス内の表も含む。ダッシュと0円を区別する。仮払い等の本文中の金額を含む文書全体はファイルSHA256で固定する。
- `04_成果物/2026-11_LOCK/approval.json`：会話での承認内容・範囲。記録時刻とユーザーの実承認時刻を混同せず、実承認時刻は未指定として保持する。
- [LOCK指紋の控え](2026-11-conditions-lock.json)：Gitへコミットする検証基準。金額・Word本体は既存のGit除外方針に従う。

## 検証

プロジェクト直下で実行する。

```powershell
$receipt = Get-Content -Raw -Encoding UTF8 "docs/2026-11-conditions-lock.json" | ConvertFrom-Json
py scripts/lock_conditions.py verify `
  --output "04_成果物/2026-11_LOCK" `
  --expected-manifest-sha256 $receipt.manifest_sha256
```

検証はGit管理された指紋とLOCKマニフェストを照合し、正本・LOCKコピー・金額スナップショット・承認記録の変更、除外対象混入、文書ペア不足、余分なファイルを拒否する。既存LOCKへの上書きはできない。

LOCKは指紋による改変検知と承認スナップショットの固定であり、OSの編集権限を奪う仕組みではない。変更が必要な場合は別版を作成し、再承認した上で新しいLOCKと指紋の控えを作る。

## メール自動化への引継ぎ

対象10社と添付候補はLOCKのマニフェストを正本とする。次のメール自動化では添付前にこの検証を必須にし、フォルダの一括検索で送信対象を決めない。`2026-11_その他8社`の集合ZIPや作業記録、古いPhase 2比較ブックは代理店への添付対象ではない。既存P5の粗利計算からこのWordを再生成しない。

現段階ではメール自動化への接続・送信は実施していない。`approval.json`の`email_send_approved`はfalse。宛先・本文・添付・送信方法は次の作業で確認する。
